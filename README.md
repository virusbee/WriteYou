# 介绍

一款简约的写作App，支持markdown。

采用四栏布局管理文章：文章列表、素材面板、markdown编辑器、暂存区。


### 文章列表
一篇文章作为一个workspace进行管理，一个workspace对应硬盘上的一个文件夹，主要包含文章文件md、素材图片、暂存文件md。

### 素材面板
写文章准备阶段，可以把图片素材先保持到这里统一管理，实时同步磁盘文件夹。可以编辑素材：改名称、加水印、改大小。

### markdown编辑器
文章编辑区域，支持markdown语法，支持两种样式（在菜单中切换）。可以从素材面板拖拽图片到文章指定位置，也可以直接从剪贴板粘贴图片。

### 暂存区
记录灵光一闪的想法、想要调整/优化的点、怕等会就忘记的点。

# Introduction

A minimalist writing app that supports Markdown.

Manage articles using a four-column layout: article list, asset panel, Markdown editor, and staging area.

### Article list
Each article is managed as a "workspace," which corresponds to a folder on your hard drive. This folder typically contains the article file (in Markdown format), any associated images, and temporary Markdown files.

### Asset panel
During the preparation phase of writing an article, you can store and manage your image assets here; the platform stays synced with your local disk folders in real time. You can also edit these assets—renaming them, adding watermarks, or adjusting their dimensions.

### Markdown editor
The article editing area supports Markdown syntax and two styles (which can be switched in the menu). You can drag and drop images from the asset panel to a specified location in the article, or paste images directly from the clipboard.

### Staging area
Capture sudden flashes of inspiration, areas for adjustment or optimization, and points you’re worried you might otherwise forget.
